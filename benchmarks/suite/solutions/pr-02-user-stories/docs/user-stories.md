# User stories

## Order tracking

As a customer, I want to see where my order is, so that I know when it arrives.

Acceptance criteria
- Given a shipped order, when I open it, then I see its carrier status.

## One-click reorder

As a customer, I want to reorder a past basket, so that I save time.

Acceptance criteria
- Given a past order, when I press reorder, then its items are in my cart.

## Saved addresses

As a customer, I want to reuse my address, so that checkout is faster.

Acceptance criteria
- Given a saved address, when I check out, then it is preselected.

## Shipping email

As a customer, I want an email when my order ships, so that I can plan to receive it.

Acceptance criteria
- Given an order, when it ships, then I get an email.

## Typo-tolerant search

As a customer, I want search to forgive typos, so that I find products.

Acceptance criteria
- Given a product named Kettle, when I search Ketle, then Kettle is in the results.

## Saved cards

As a customer, I want to pay with a saved card, so that I do not type it each time.

Acceptance criteria
- Given a saved card, when I pay, then I can choose it.
